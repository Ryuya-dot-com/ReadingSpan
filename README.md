# Reading Span Task（Last-Letter Recall）

ブラウザだけで実行できる Reading Span（意味判断＋末尾文字リコール）課題です。ローカルで `index.html` を開けば動作します。

## 特徴
- 課題フローを自動進行：練習フェーズ1/2と本試行を順に実施
- 意味判断後に末尾文字をフラッシュ提示し、セット末に入力
- 初回提示前2秒、その後500msの注視点で視線を安定化
- 本試行完了時に結果を自動で Excel（XLSX）保存
- 戻る/再読み込み時に警告を表示し、誤操作によるデータ消失を防止

## 使い方
1. `index.html` をブラウザで開く（ネット接続不要。xlsx生成のため外部CDN読み込みが必要な場合があります）。
2. 氏名と参加者IDを入力し「説明に進む」を押す。
3. フェーズ1（意味的適否の判断練習）→フェーズ2（末尾文字リコール練習）を実施。
4. 練習完了後、「本試行を開始」で本試行を実施。
5. 結果画面表示と同時に Excel ファイルが自動でダウンロードされます。

## 操作（キーボード中心）
- 意味判断：`J` = True（意味的に適切） / `F` = False（意味的に不適切）
- セット終了後の文字入力：各欄に1文字ずつ入力し、スペースキーで送信（ボタン不要）
- スペースキーは、入力欄にフォーカスがないとき、画面遷移のショートカットにも使用

## 出力
- ファイル名：`ReadingSpan_参加者名_ID_YYYYMMDD-HHMMSS.xlsx`
- シート構成：
  - `trial_log`: 全試行のログ（処理・リコール）
  - `summary`: 集計値（処理正答率、締切、練習RTなど）
  - `set_stats`: セット長ごとの正答率・完全正答数

## 注意
- ブラウザの戻る/再読み込みで警告が出ます。進行中はページ遷移しないでください。
- 文字化け防止のため CSV ではなく XLSX のみ出力します。
- レイテンシ計測や刺激提示はブラウザ依存です。実験環境は統一してください。
